## Findings

- **Repository hygiene.** 22,131 files under `node_modules/`, `dist/`, `.angular/`, `test-results/` and `playwright-report/` are tracked (B-001). The previous `.gitignore` ignored `.claude` entirely, so new shared agent files would not have been committed; fixed here (only local Claude state is ignored now).
- **CI and deploy.** No workflow ran on pull requests; the harness adds `CI`. Two identical deploy workflows run on every push to `main`, and `.gh-workflow/` holds a third copy (B-002).
- **Contradicting rules.** ESLint (`prefer-on-push-component-change-detection`) and the `frontend-angular` subagent required explicit `OnPush`, against the Angular v22 default the harness rules follow. The ESLint rule was replaced by `prefer-inject` and `no-explicit-any` (both pass) and the subagent now points to AGENTS; the code is B-003.
- **Engine determinism.** `Math.random()` inside `tick()` (blood particles) breaks the deterministic-engine rule (B-004).
- **Documentation drift.** GAME-DESIGN frame data uses frames and other move names than the code's millisecond tables (B-005). ART-DIRECTION's palette and fonts differ from the shipped tokens and loaded fonts (B-007). The style guide documents what ships.
- **Style.** Component styles use literal colours, never the tokens (B-006). No focus styles, no reduced-motion handling, no accessibility checks (F-003).
- **Assets.** PNG generation (`tools/gen_sprites.py`) and SVG rigs (`parts/frames.ts`) coexist with no stated owner (F-002).
- **Naming.** `marginalia-fighters` (package, Angular project, build output) versus `marginalia-wars` (repository, site) (F-004).
- **Privacy.** No secrets or personal data found in the tracked source and docs. Image metadata in `public/assets/references/` was not checked; do that with F-002.

## Not covered

Gameplay feel, visual review of the arena and sprites, and real browsers other than the headless Chromium the e2e suite uses.
